AuraQuote — Personalized Motivational Cards
A full-stack web application that uses Google Gemini AI to synthesize bespoke motivational quotes harmonizing an individual's profession with their creative hobbies and passions. Quotes are rendered on customizable, high-resolution aesthetic cards ready for instant download as PNG images or PDF prints.
Features
Personalized AI Synthesis: Blends the discipline and mechanics of any occupation with the freedom and spirit of any hobby using Gemini 3.8 Flash.
Atmospheric Visual Backdrops: High-quality photographic and minimalist themes (Summit Dawn, Artisan Atelier, Celestial Void, Zen Sanctuary, Obsidian Minimal, and Nebula Silk).
Format & Aspect Ratios: Switch between Square (1:1) for social posts, Story (9:16) for mobile wallpapers, and Banner (16:9) for desktop headers.
Editorial Typography: Choose between Cormorant Garamond, Instrument Serif, Plus Jakarta Sans, and Cinzel.
High-Resolution Export: Export 2.5× retina PNG cards using client-side rasterization (html-to-image) or formatted print/PDF documents.
Saved Inscriptions Library: Save, browse, and re-export quotes locally via browser storage.
Philosophical Mindset Reflections: Breaks down the cognitive synergy and transferable lessons between your work and play.
Tech Stack
Frontend: React 19, Vite, Tailwind CSS v4, Lucide React, Motion, html-to-image
Backend: Node.js, Express, tsx
AI Engine: @google/genai TypeScript SDK (gemini-3.8-flash)
